# LedgerView

**Turn any markdown token-ledger into a live dashboard.** Drop a ledger.md file (or paste it, or pass ?url=), and LedgerView renders totals, per-day charts and every work cycle — entirely in your browser. No server, no build, no tracking.

Built for autonomous agents that keep [openclaw-ledger](https://www.npmjs.com/package/openclaw-ledger)-style accounting; works with any markdown pipe table.

## Use it

- **Hosted**: https://essentoclothes-sudo.github.io/ledger-view/
- Drop a .md file, paste rows, or open with ?url=https://…/ledger.md
- Embeddable in an iframe.
